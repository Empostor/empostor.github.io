# 指令参考

游戏内指令在聊天框中输入，以 `#` 前缀开头。`#help` 会列出当前服务器可用的全部指令 —— 插件指令只有在对应插件已安装并启用时才会出现。

| 分类 | 数量 |
| :--- | :--- |
| [内置指令](#内置指令) | 9 条，始终可用 |
| [插件指令](#插件指令) | 6 条，取决于已安装的插件 |

## 内置指令

随服务器自带，无需任何插件。

### 所有人可用

| 指令 | 别名 | 用法 | 说明 |
| :--- | :--- | :--- | :--- |
| `#help` | — | `help [command]` | 显示可用指令，或查看某条指令的详情。 |
| `#ping` | — | `ping` | 显示你的当前延迟。 |
| `#players` | — | `players` | 列出当前房间内的玩家及其延迟。仅限大厅使用。 |
| `#setcolor` | `#sc`、`#color` | `setcolor [0-17]` | 修改你的角色颜色，有效范围 0–17。 |
| `#stat` | `#stats`、`#mystats` | `stat` | 查看你本人的统计数据。需要[玩家统计](../plugins/player-stats.md)插件已启用。 |

### 仅房主可用

| 指令 | 别名 | 用法 | 说明 |
| :--- | :--- | :--- | :--- |
| `#note` | — | `note [文本 \| clear]` | 设置或清除房间备注。 |
| `#max` | — | `max [1-127]` | 设置房间最大人数，有效范围 1–127。 |
| `#kick` | — | `kick <玩家> [理由]` | 按好友代码或昵称踢出玩家。 |
| `#ban` | — | `ban <玩家> [理由]` | 按好友代码或昵称封禁玩家。 |
| `#end` | — | `end [理由]` | 强制结束当前游戏。 |

::: warning 超过 15 人需要客户端 Mod
大于 15 的数值要求所有玩家都装有 CrowdedMod 或其他支持多人大厅的 Mod。设置更高数值时服务器会给出相应警告。
:::

## 插件指令

由官方插件提供，未安装对应插件时不可用。

| 指令 | 别名 | 用法 | 所属插件 | 权限 |
| :--- | :--- | :--- | :--- | :--- |
| `#narrator <问题>` | `#nar`、`#n` | 向 AI 寻求会议建议 | [旁白 AI](../plugins/narrator.md) | 所有人 |
| `#votemap <地图>` | `#vm` | 投票选择下一张地图 | [地图投票](../plugins/map-vote.md) | 所有人 |
| `#msg <好友代码> <消息>` | `#message`、`#leave` | 给玩家留离线消息 | [留言系统](../plugins/leave-a-message.md) | 所有人 |
| `#channel <消息>` | — | 发送到你的玩家频道 | [玩家频道](../plugins/player-channel.md) | 所有人 |
| `#stat` | `#stats`、`#mystats` | 查看你的统计 | [玩家统计](../plugins/player-stats.md) | 所有人 |
| `#verify <QQ号>` | `#ver` | 发起 QQ 验证 | [QQ 群验证](../plugins/qq-verify.md) | 所有人 |

部分插件还提供仅房主可用的子指令 —— 例如 `#votemap start` / `#votemap end`、`#narrator enable` / `#narrator limit`。完整列表见各插件页面。

## 别名

别名是同一条指令的替代名称。`#sc 3`、`#color 3` 与 `#setcolor 3` 效果完全相同。`#help` 会显示每条指令的别名。
