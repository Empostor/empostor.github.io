# 自定义房间代码

**插件 ID：** `cn.hayashiume.code`
**配置：** 无 —— 词表来自 `Boot.Codes/` 目录

| 参考内容 | 位置 |
| :--- | :--- |
| 配置 | 无 —— `.txt` 词表目录 |
| 指令 | 无 |
| 管理面板 | 无 |
| HTTP API | 无 |

用可读的房间代码（如 `SUNSET`、`ROCKET`）替代随机的六位代码。

## 词表

将 `.txt` 文件放入服务器工作目录的 `Boot.Codes/` 文件夹：

```
Empostor/
├── Boot.Codes/
│   ├── words.txt
│   ├── animals.txt
│   └── colors.txt
├── config/
├── plugins/
└── ...
```

每个 `.txt` 文件都是一份词表，每行一个候选代码；`--` 开头为注释，空行跳过：

```
-- 常用词
SUNSET
ROCKET
DRAGON
TEMPLE

-- 动物
PANDA
WHALE
```

**规则**

| 规则 | 说明 |
| :--- | :--- |
| 长度 | 必须为 **4 或 6** 个字符 |
| 字符集 | 仅限大写 `A`–`Z` |
| 非法行 | 静默跳过 |
| 顺序 | 启动时随机打乱 |
| 复用 | 游戏结束后代码回到可用池 |

::: tip 跨文件重复的词
同一单词出现在多个文件中只算一个代码。可用池是所有文件的并集。
:::

## 兜底行为

`Boot.Codes/` 不存在、为空或代码耗尽时，服务器回退到默认的随机六位代码生成器。新增词汇无需重启，下次分配即生效。
