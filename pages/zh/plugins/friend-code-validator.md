# 好友代码验证

**插件 ID：** `duck.Empostor.friendcodevalidator`（市场上为 `duck.hayashiume.friendcodevalidator`）
**配置文件：** 无 —— 校验规则内置编译

| 参考内容 | 位置 |
| :--- | :--- |
| 配置 | 无 |
| 指令 | 无 |
| 管理面板 | [信息标签页](#管理面板) |
| HTTP API | 无 |

拒绝好友代码未通过校验的连接请求。

## 校验规则

好友代码必须**同时**满足以下两条才会被放行：

| # | 规则 | 说明 |
| :-- | :--- | :--- |
| 1 | 格式 | 匹配 `^([a-zA-Z]+)#(\d{4})$` —— 字母 + `#` + 恰好 4 位数字。 |
| 2 | 词典 | 字母部分必须是内置英文词典中的词（5000+ 词条）。 |

任意一条不满足，客户端将被断开，并收到本地化提示。

::: warning 词典会拒绝非英文昵称
`xXxSlayer` 这类昵称不是词典词，会被拒绝。没有白名单机制，仅适用上述两条规则。
:::
