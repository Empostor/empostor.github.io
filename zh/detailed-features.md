# 详细功能

Empostor 除了基础的服务器托管外，还内置了丰富的功能集。本部分涵盖所有开箱即用的高级功能。

---

## 管理面板

**[管理面板](Admin-panel.md)** 是一个内置的 Web 界面，位于 `http://your-server:22023/admin`。提供以下功能：

| 功能 | 描述 |
|---|---|
| 仪表盘 | 实时服务器统计：游戏、玩家、封禁、运行时间 |
| 游戏管理 | 列出活跃游戏、查看玩家、结束游戏 |
| 客户端管理 | 查看已连接客户端及模组详情 |
| 广播 | 向所有活跃游戏发送消息 |
| 踢出/封禁 | 按 ID、IP 或好友代码移除或封禁玩家 |
| 隐私切换 | 切换游戏的公开/私密状态 |
| 插件市场 | 从市场 URL 浏览和安装插件 |
| 更新检查 | 将运行版本与最新 GitHub 发布版进行比较 |
| 举报 | 查看游戏内玩家举报 |
| 玩家日志 | 浏览每个玩家的活动日志 |
| 统计 | 跟踪每个玩家的游戏统计 |
| 聊天过滤 | 配置屏蔽词和刷屏保护 |
| Discord 通知 | 配置 Discord 通知 Webhook |
| HPLP | 配置 Starlight 客户端发现 |
| 称号系统 | 管理玩家称号前缀 |

---

## 聊天过滤

**[聊天过滤](Admin-panel.md#聊天过滤)** 提供内置的游戏内聊天管理功能。配置屏蔽词、切换阻止/仅记录模式，以及设置刷屏速率限制——全部可在管理面板中完成。

---

## Discord 通知

**[Discord 通知](Discord-webhook.md)** 将游戏事件直接发送到 Discord 频道。包括游戏创建、玩家加入、举报、封禁和游戏结束的通知。

---

## 玩家统计

**[玩家统计](PlayerStats-plugin.md)** 跟踪每个玩家的游戏数据：胜场、败场、内鬼胜场、击杀、死亡、完成任务等。可在管理面板和 `#stat` 命令中查看。

---

## 服务器监控

**[服务器监控](Monitor-plugin.md)** 提供用于健康检查和状态仪表板的 HTTP API 端点。适用于外部监控工具和负载均衡器。

---

## 隐私政策

**[隐私政策](Privacy-plugin.md)** 提供可配置的隐私政策页面以及更新其内容的 API。适用于需要遵守隐私法规的服务器。

---

## 地图投票

**[地图投票](MapVote-plugin.md)** 允许玩家在游戏期间使用聊天命令投票选择下一张地图。得票最多的地图自动被选中。

---

## 旁白（AI 顾问）

**[旁白](Narrator-plugin.md)** 在会议期间提供 AI 驱动的战略顾问。玩家可以向 AI 寻求基于角色、游戏状态和聊天记录的上下文建议。

---

## 称号系统

**[称号系统](Titles-plugin.md)** 通过好友代码为特定玩家分配显示称号前缀（例如 `[Empostor]`）。称号可通过配置、管理面板或 HTTP API 添加。

---

## 欢迎消息

**[欢迎消息](Welcome-plugin.md)** 在玩家加入大厅时发送本地化的欢迎消息。支持 16 种语言、占位符、远程 URL 内容和随机消息选择。

---

## 玩家频道

**[玩家频道](Player-channel-plugin.md)** 提供基于好友代码的跨游戏聊天频道。可在不同房间中与好友沟通。

---

## 留言系统

**[留言系统](Message-plugin.md)** 允许玩家通过好友代码互相留言。收件人加入时自动投递。

---

## QQ 验证

**[QQ 验证](QqVerify-plugin.md)** 提供 QQ 号码验证系统，用于将游戏内账户关联到 QQ 账户进行社区管理。

---

## 好友代码验证

**[好友代码验证](FriendCodeValidator-plugin.md)** 根据格式模式和内置安全词典验证玩家好友代码。

---

## 插件市场

**[插件市场](Admin-panel.md#插件市场)** 允许管理员从管理面板浏览和安装社区插件。插件在 `plugins.json` 文件中定义——详情请参阅[可配置文件](configurable-files.md)参考。
